# Event-Website

This projectis a wedding website which is a simple, static personal website built using HTML, CSS, and JavaScript. It features a homepage and a separate Contact Us page, making it ideal as a starting point for a personal portfolio or project showcase.


## Project Structure

Event-Website
- index.html         # Main homepage
- contact.html       # Contact page
- styles.css         # Stylesheet for layout and design
- index.js           # JavaScript for interactive behavior
- README.md


## Features

- Clean and responsive design
- Modular structure for easy customization
- Simple HTML/CSS/JS stack (no frameworks required)
- Separate Contact page


## Getting Started

To view or modify the website locally, follow these steps:

1. **Clone or Download** this repository:
   ```bash
   git clone https://github.com/your-username/DCheruvu_WEB101.git
   ```
   Or download the ZIP and extract it.

2. **Open the project**:
   Navigate to the extracted folder and open `index.html` in any modern web browser.

3. **Edit files as needed**:
   - Use any text editor or IDE (e.g., VS Code) to modify `index.html`, `contact.html`, `styles.css`, or `index.js`.
